# Company website

This is basic website for a company that offers massage services. Application uses typescript and react for the frontend. Website currently has no backend and time reservations are handel by API calls to outside services

This website has been solo deveploment by mean and is not expected to be made public

# Building 

Normal npm build process so : 

npm i 
npm run build
npm run dev


# Version control and deployment

Version control is done using github using to branches dev and main(which is the production branch). Both which are hosted online.

Deployment is done using Amazon Amplify and is deployd directly from github. 
Sites can be seen at https://hierojaelsaikola.fi/ and https://dev.d36hbncpdtx8h2.amplifyapp.com/
